# STARFALL — Sector 07

小さな宇宙機で前線を突破する、Godot 4 製の縦スクロール・シューティングのプロトタイプです。昔ながらのアーケード作品をヒントにしつつ、機体・背景・敵・音楽はこのプロジェクトのために独自に制作しています。既存作品の画像や音源は使用していません。

**144 秒の道中 ＋ 最後のボス「THE WARDEN」**。大量の弾を避け続ける弾幕型ではなく、敵の動きを読みながら移動・連射するシンプルな 1 ステージです。ボス戦の長さは攻撃の当て方によって変わります。

- 上下左右移動、押しっぱなし連射、低速移動
- 4 種類の通常敵と、予兆を伴う 3 パターンの攻撃を使うボス
- 3 段階の武器強化、スコア、残機、被弾後の無敵時間
- タイトル、ポーズ、ゲームオーバー、クリア、リトライ
- オリジナルのベクター描画、縦スクロールする宇宙背景、効果音、48 秒ループ BGM
- キーボード操作と基本的なゲームパッド割り当て

## 必要な環境

**Godot 4.6.3 Standard 版（GDScript）**を開発・検証対象にしています。`.NET` 版、外部アドオン、Python パッケージは不要です。レンダラーは **GL Compatibility**、内部表示サイズは **480 × 720** です。

Mac / Apple Silicon（M1 以降）へ持ち込めるソースプロジェクトです。ただし、**Mac 実機での動作確認や macOS 向け `.app` の書き出し・署名はまだ行っていません**。納品物はネイティブ実行ファイルではなく、Godot で開いて実行・編集するためのプロジェクトです。

## Mac で開く

1. Godot 4.6.3 の Standard 版を用意します。
2. ZIP を展開するか、リポジトリをクローンします。
3. Godot のプロジェクトマネージャーで **インポート**を選び、フォルダー内の `project.godot` を指定します。
4. 初回インポートが終わったら **F5**（プロジェクトを実行）。Mac のキーボード設定によっては **fn + F5** を使います。
5. `scenes/main.tscn` を開いて **F6**（現在のシーンを実行）でも開始できます。

Godot のエディター上部にある実行ボタンも使用できます。ゲーム中のウィンドウからフォーカスが外れると、自動的にポーズします。

リポジトリ: <https://github.com/you-sk/godot-vertical-shooter>

```sh
git clone https://github.com/you-sk/godot-vertical-shooter.git
cd godot-vertical-shooter
```

## 操作

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| 移動 | 矢印 / WASD | 左スティック / 十字キー |
| ショット | Z / Space（押しっぱなし） | A 相当の下側ボタン |
| 低速移動・当たり判定の表示 | Shift | LB / 左ショルダー |
| 開始・メニュー決定 | Enter | A 相当 |
| メニュー選択 | 上 / 下 | 十字キー上 / 下 |
| 一時停止・再開 | Esc / P | Start |
| ミュート切替 | M | — |
| メニュー決定の代替 | R | — |

メニューのボタンはマウスでもクリックできます。リザルト画面の先頭項目で Enter / R を押すとリトライ、2 番目の項目はタイトルに戻ります。リザルト画面では Esc でもタイトルに戻れます。プレイ中に R を押しても即座にはリセットされません。

ゲームパッドのボタン表示は標準的な Xbox 系配置を基準にしています。実際の名称・対応は機種や OS によって異なり、**物理ゲームパッドでの確認は未実施**です。

## 遊び方

- 初期シールド（残機）は 3。被弾すると 1 減り、武器が 1 段階下がります。
- 被弾後は中央下へ戻り、約 2.8 秒間無敵になります。近くの敵弾も消去されます。
- 強化アイテムで武器は最大レベル 3 まで成長し、500 点を獲得します。
- 15,000 点ごとにシールドが 1 増えます（最大 5）。ボス撃破は 10,000 点。
- 自機中央の小さな判定を意識し、接近しすぎずに射線を合わせるのが基本です。
- 144 秒で道中が終了し、残った通常敵と敵弾を整理してボスが登場します。

ベストスコアは Godot のローカル保存先 **`user://scores.cfg`** に保存されます。アカウント、オンライン通信、ランキング送信、API キーは使用しません。

## コマンドライン実行・検証

以下はプロジェクトのルートから実行します。`godot` は Godot 実行ファイルを PATH から呼び出せる場合の表記です。GUI から遊ぶだけなら CLI の設定は不要です。

```sh
# キャッシュのない環境で、まずリソースをインポート
godot --headless --path . --editor --quit

# 通常起動
godot --path .

# 自動テスト
godot --headless --path . --script tests/test_runner.gd

# 音源のフォーマット・クリッピング・ループ境界を検証
python3 tools/generate_audio.py --validate-only
```

実施済みの結果は [docs/VERIFICATION.md](docs/VERIFICATION.md) に記録しています。テスト内容と引き継ぎの詳細は [docs/HANDOFF.md](docs/HANDOFF.md) を参照してください。この README のコマンド一覧は手順であり、すべての OS での成功を保証するものではありません。

## 構成

```text
project.godot             プロジェクト設定
scenes/main.tscn          起動シーン
scripts/                 ゲーム本体・各アクター・音声・背景
assets/audio/            独自生成した WAV と制作メモ
assets/icon.svg          オリジナルのプロジェクトアイコン
tests/test_runner.gd     ヘッドレス自動テスト
tools/generate_audio.py  音源を再生成・検証する Python スクリプト
docs/                    引き継ぎ・公開時の注意
```

`.godot/` は Godot が再生成するキャッシュで、Git・配布 ZIP には含めません。音源の再生成には Python 3 の標準ライブラリーだけを使います。ゲームの実行に Python は不要です。
