# 公開・引き継ぎ時の確認

このプロジェクトは、アカウント・API キー・外部サービス・ネットワーク通信を必要としないローカルゲームです。

## 公開対象

- Godot のシーン、GDScript、設定、オリジナル SVG / WAV、テスト、生成スクリプト、文書。
- WAV は `tools/generate_audio.py` で独自に合成したものです。既存楽曲、録音サンプル、外部サウンドフォントは使用していません。
- 機体・敵・背景はプロジェクトのコードで独自に描画しています。既存ゲームの画像・ロゴ・キャラクターを取り込んでいません。
- ライセンスはまだ選定していません。公開リポジトリで閲覧できることと、再配布・二次利用の許諾は別です。

## 含めないもの

`.gitignore` で `.godot/`、OS の一時ファイル、ログ、ビルド出力、書き出し用資格情報などを除外しています。公開前には除外ルールだけに頼らず、`git status` と `git diff --cached` で実際の対象を確認してください。

- `.godot/` などの生成キャッシュ、個人のエディター状態。
- トークン、パスワード、証明書、署名用鍵、`export_credentials.cfg`。
- 絶対的な個人パス、アカウント情報、環境固有の設定。
- `user://scores.cfg` のローカルセーブデータ。
- 不要な実行ログ、録画、検証用の大きな生成物。

同梱の `.import` ファイルは Godot のインポート設定です。再生成可能なバイナリキャッシュ本体の `.godot/` とは区別します。

## ローカル保存

保存するゲームデータはベストスコアのみです。保存先は Godot が管理する `user://scores.cfg` で、サーバーへの送信やアカウントとの関連付けはありません。デバッグ用キャプチャは指定した出力先に PNG を書き出すため、公開用 ZIP に含める画像は内容を確認してください。

## 配布と Mac

ソースの公開は macOS アプリの署名・公証を意味しません。実行ファイルとして配布する段階では、利用者が選ぶ配布方法に応じて書き出しテンプレート、署名・公証、ライセンス、同梱物を別途確認してください。署名用の秘密情報をリポジトリへ追加しないでください。
