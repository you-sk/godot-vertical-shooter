# 検証記録

検証日: 2026-10-29。対象: Godot **4.6.3.stable.official.7d41c59c4**、Linux、GDScript / GL Compatibility。

## 実施結果

| 対象 | 結果 |
|---|---|
| ヘッドレス初回インポート | 成功 |
| ヘッドレス起動 | 成功、スクリプトエラーなし |
| `tests/test_runner.gd` | **50 チェック成功、失敗 0** |
| 通しシミュレーション | 150 秒分の通常ステージ・ボス登場を実行 |
| ボス撃破 | HP 340 のボスに基本武器の通常弾だけを当てて撃破。登場から約 30.15 秒 |
| 描画 | 実際の Godot ウィンドウでタイトル・通常戦・ポーズを確認。6 種の画面をエンジンから PNG 出力し確認 |
| 操作 | マウスで開始、Enter 開始、キー入力で射撃・移動、Esc メニュー遷移・ポーズを確認 |
| 音源 | 8 WAV の読込、BGM ループ設定、ミュート切替、フォーマットと波形検証に成功 |

ボス撃破の自動検証では、敵の位置へ射線を合わせるテスト制御と無敵を使用しています。**通常プレイのクリア率・難易度の保証ではありません**。

## 自動テストの範囲

- 初期状態、全音源読込、キー / ゲームパッド割り当て。
- 斜め移動の正規化、画面内制限、連射と弾の移動・画面外破棄。
- 通常敵 4 種の生成・射撃、敵撃破と重複しない加点。
- 敵弾 / 体当たりの被弾、無敵時間、残機、ゲームオーバー。
- リトライ、ポーズ・再開、ミュート、タイトルへの復帰。
- 強化アイテム、武器レベル上限、追加残機。
- 144 秒の道中、4 回のアイテム出現、アクター数の上限検査。
- ボス登場中の保護、3 種の攻撃、撃破、クリア後の再挑戦。
- **ボス移行時に消した敵から敵弾が復活しない**回帰テスト。
- 全 HP のボスを通常弾だけで撃破するテスト。

高速シミュレーションでは音声ファイルをロードしますが、実時間の音声再生は抑制しています。通常ゲームでは再生が有効です。

## 音源の数値検証

- すべて mono / 22,050 Hz / 16-bit PCM WAV。
- BGM: 48.000 秒、24 小節 / 120 BPM。
- BGM 最大絶対振幅: 0.78、RMS: 0.1724、ループ境界のサンプル差: 0.003388。
- 8 ファイルすべてクリッピング 0、合計 2,303,032 bytes。
- 標準ライブラリーの生成スクリプトから再生成可能。

## 未検証・環境上の制限

- **Mac / Apple Silicon 実機、macOS ネイティブ書き出し、署名・公証は未検証**。
- 物理ゲームパッドは未接続。割り当ての構成のみ確認。
- 検証用 Linux デスクトップに利用可能な音声出力ドライバーがなく、Godot はダミー出力へフォールバック。実際に聞いた音量・音色・ループの体感品質は未確認。
- Linux デスクトップでは V-Sync 変更非対応の警告が出ました。描画・操作は継続できました。
- 手動での全ステージ・ボスの通常クリア、長時間連続プレイ、Mac での保存データ永続化は今後の確認項目です。

## 再現

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script tests/test_runner.gd
python3 tools/generate_audio.py --validate-only
```

視覚確認は GUI で F5、画像再生成は `tests/visual_capture.tscn` を開いて F6 を使用してください。
